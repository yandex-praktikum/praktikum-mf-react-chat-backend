# Сервер чата дипломного проекта Яндекс.Практикум

## Технологии
* Node
* Express 
* Passport 
* Socket.io

## Описание
Простейший вариант авторизации. Пользователи хранятся в локальном массиве (изменения исчезнут после рестарта)

## Настройка
Точка входа — index.js.   
Развёрнут на heroku

## Запуск
`yarn start` или 
`npm start`

## Часто используемые команды
```bash
heroku restart

heroku logs --tail

git push heroku master
```
