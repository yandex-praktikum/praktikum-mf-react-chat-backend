### Сервер чата дипломного проекта Яндекс.Практикум

Node, Express, Passport, Socket.io

Простейший вариант авторизации

Пользователи хранятся в локальном массиве (изменения исчезнут после рестарта)

Точка входа -- index.js

### Запуск
`yarn start`
or
`npm start`

### Развёрнут на heroku

Часто используемые команды
```
heroku restart

heroku logs --tail

git push heroku master
```
